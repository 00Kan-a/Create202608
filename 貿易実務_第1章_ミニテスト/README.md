# 貿易実務検定 第1章「海上貨物輸送」ミニテスト

毎日10問が自動出題される学習アプリです。インストール不要、インターネット接続も不要です。

## 起動方法

`index.html` をダブルクリックするだけです（Chrome / Edge 推奨）。

デスクトップにショートカットを置いておくと毎日の習慣にしやすいです。

## できること

- **今日の10問** … 全188問のプールから、日付ごとに自動で10問を選んで出題します。日付が変われば自動的に新しい10問に切り替わります。同じ日に開き直しても問題は変わりません（途中でやめても続きから再開できます）。
- **まちがえ優先** … 一度まちがえた問題は、翌日以降のテストで最大4問まで優先的に再出題されます。
- **復習モード** … これまでにまちがえた問題だけを、まとめて解き直せます。日々の記録には影響しません。
- **成績タブ** … 連続日数、実施日数、プール網羅率、分野別（1-1〜1-6）の正答率、直近14日の得点グラフ、苦手な問題ワースト10 を確認できます。
- **記録の書き出し／消去** … 成績タブの一番下から行えます。

## 出題形式

- ○×問題（149問）
- 4択問題（39問）

回答するとその場で正誤と解説が表示されます。

## 注意

- 学習記録は、この端末のブラウザ内（localStorage）にのみ保存されます。別のPCやブラウザ、シークレットウィンドウでは引き継がれません。
- ブラウザの「閲覧履歴データの削除」でサイトデータを消すと記録も消えます。心配なときは成績タブから JSON を書き出して保管してください。

## ファイル構成

```
index.html     … アプリ本体（画面・出題ロジック・記録）
questions.js   … 問題プール（ここに追記すれば問題を増やせます）
README.md      … このファイル
```

## 問題を追加したいとき

`questions.js` を、メモ帳やVS Codeなどのテキストエディタで開き、末尾の `];` の直前に次の形式で追記します。`id` は他と重複しない数字にしてください。

```js
{id:300,sec:"1-2",type:"ox",q:"問題文をここに書きます。",a:true,
 exp:"解説をここに書きます。"},

{id:301,sec:"1-4",type:"mc",q:"問題文をここに書きます。",
 choices:["選択肢1","選択肢2","選択肢3","選択肢4"],a:2,
 exp:"解説をここに書きます。"},
```

- `sec` … `"1-1"`〜`"1-6"` のいずれか
- `type` … `"ox"`（○×）または `"mc"`（4択）
- `a` … ○×なら `true` / `false`、4択なら**正解の選択肢が上から何番目か（0から数える）**。上の例の `a:2` は「選択肢3」が正解の意味です。

保存してブラウザを再読み込みすれば、すぐに出題プールに加わります。
